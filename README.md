## ✨ Features
- AI question solving
- Text questions
- Question image upload
- Maths, Physics, Chemistry, Biology and other subjects
- Hindi, English and Hinglish answers
- School and College levels
- Copy answer
- Text-to-speech
- Recent question history

## 🛠️ Technology
- HTML
- CSS
- JavaScript
- Vercel
- Gemini API
